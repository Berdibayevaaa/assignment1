DOCTYPE html — tells the browser this file is written in HTML5.
html — root tag that holds all the code of the webpage.
head and title — head stores settings and metadata, and title sets the name on the browser tab (My First Webpage).
body — contains all visible parts of the page.
h1, h2, h3 — headings for content hierarchy:
h1 for my name to make it the biggest and most noticeable title.
h2 for my group and year.
h3 for section names like About Me, Hobbies, and Links.
p — standard paragraph tag to keep text clean and readable.
ol and li — ordered list with automatic numbers (1, 2, 3) for my top 3 hobbies.
ul and li — unordered bullet list for favorite websites where order does not matter.
img — embeds my photo via src="profile.jpg", with alt text if the image fails to load.
a — creates clickable links with target="_blank" so sites open in a new tab.
button — adds a simple clickable button to the page.

I used these basic HTML tags to create a clean page structure and divide information into clear sections. Everything opens and runs without errors.

CSS methods and selectors I used:
- Inline CSS — added style="font-size: 16px; line-height: 1.6;" directly into the paragraph to quickly adjust its text size and line height.
- Internal CSS — used style tags inside head to style the schedule table with background colors and clean border collapse.
- External CSS — created a separate style.css file and linked it via link rel="stylesheet" href="style.css" to keep the code clean and organized.
- Tag Selector — body in style.css to set the main font family, page background, and text color.
- ID Selector — #main-heading to give my name a distinct dark blue accent color.
- Class Selector — .highlight to give the About Me block a soft highlight background and a left border.

Connected CSS in three different ways (inline, internal, and external). Used tag, id, and class selectors to style typography, colors, and layout.
